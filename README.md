# Análise Exploratória de Dados de Crédito (EDA)

Este projeto apresenta uma Análise Exploratória de Dados (EDA) aplicada a um conjunto de dados relacionados a crédito, com o objetivo de investigar padrões e insights que possam ser relevantes para avaliação de risco de crédito.

📊 Objetivo
O objetivo principal é explorar os dados de crédito para:

* Compreender a distribuição das variáveis;
* Identificar relações entre características dos clientes e inadimplência;
* Apoiar decisões baseadas em dados para instituições financeiras.

🛠️ Ferramentas e Tecnologias
O projeto foi desenvolvido em SQL utilizando o ambiente AWS Athena.

📁 Estrutura do Projeto

├── credit_eda.ipynb       # Notebook com a análise completa
├── README.md              # Este arquivo

🧪 Etapas da Análise
1. Carregamento dos dados
2. Tratamento de dados faltantes
3. Análise descritiva das variáveis
4. Visualizações gráficas
5. Insights sobre inadimplência

📌 Principais Insights
* Alguns grupos demográficos demonstram maior propensão à inadimplência.
* Há correlações relevantes entre renda, idade, e comportamento de pagamento.
* Variáveis como tempo de trabalho e número de dependentes mostraram padrões distintos entre bons e maus pagadores.
